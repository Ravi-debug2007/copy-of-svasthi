# Copy of Svasthi

A mobile-first, high-fidelity UI concept for the Svasthi mental health and wellness companion.

## What is included

- Three iPhone-style screens on a blue, lavender, and pink pastel canvas.
- Dark botanical login page with an editable email form.
- Cream dashboard with all eight requested wellness navigation tiles.
- Light sign-up page with floral heart/hand illustration and validation-ready form fields.
- Responsive horizontal mobile layout and interactive dashboard tile feedback.

The illustrations are native CSS line-art components, so they remain lightweight, responsive, and easy to change without external image assets.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL printed in the terminal.

## Verify a production build

```bash
npm run lint
npm run build
```

## Technology

- React 19
- TypeScript
- Vite
- CSS with no external UI framework required for the new design

## Notes

This repository is a UI concept. Its login, sign-up, and dashboard controls demonstrate the experience but are not connected to an authentication service. The full Svasthi API implementation lives in the separate `svasthi-web-app` repository.
